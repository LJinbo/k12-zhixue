# style.md — 全局视觉风格规范（唯一配色来源）

> 所有页面、组件的配色必须且只能取自本文件。全学段统一一套配色，不按学段区分。
> Tailwind Token 映射：`app/web/src/styles/theme.css`（与本文档 token 一一对应）。
> 新增颜色必须先修改本文件并评审，再同步进 theme.css。

## 1. 主题模式

| 模式 | 说明 | 切换 |
|---|---|---|
| 标准（默认） | 暖橘红暖色系，登录页及全部页面共用 | `html[data-mode="standard"]`（缺省） |
| 夜间 | 暖深棕底，低蓝光 | `html[data-mode="night"]`，19 点后可自动建议 |

## 3. 章节星链图配色

星球是功能性可视化节点（不属于装饰元素），颜色同样只取自本文件。

| 元素 | 标准 | 夜间 |
|---|---|---|
| 星球-已完成 | 填充 `#E9A063` / 描边 `#C77B4B` | `#B87B4E` / `#8F5E38` |
| 星球-进行中 | 填充 `#D9541F` + 外圈光环 `rgba(217,84,31,.25)` | `#E8743F` + `rgba(232,116,63,.35)` |
| 星球-未解锁 | 填充 `#D8C7B8` / 描边 `#C4B2A2` | `#5A4C42` / `#4A3B30` |
| 星链连线 | `#E3C9AF` 虚线 | `#4A3B30` 虚线 |

**星球尺寸（重要度三档）**：重点章节 大 88px ｜ 普通章节 中 68px ｜ 次要章节 小 52px。
**星球标签**：章节名用 text-primary 14px；状态用文字（已完成/进行中/未解锁），不用图形符号。

## 5. 硬性禁令

1. 禁大面积纯白 `#FFFFFF`、禁纯黑 `#000000`
2. 正文对比度 ≥ 7:1；辅助文字 ≥ 4.5:1；主色按钮文字 ≥ 3:1 且加粗 ≥16px
3. 禁闪烁/自动循环动画；转场 ≤ 200ms；奖励动效 ≤ 3 秒且可跳过
4. **禁止 emoji**：任何 UI 文案、按钮、状态、图标一律不使用 emoji；状态用文字，图标用图形或图标库
5. **禁止吉祥物与装饰性元素**：不出现任何吉祥物、卡通插画、纯装饰图形；星链图星球为功能性可视化
6. **全学段统一**：不引入任何学段专属配色、卡通皮肤；学段差异仅允许字号（小学 18 / 初中 17 / 高中 16px）与信息密度

## 6. 字体与排版

- 中文黑体系栈；正文最小 16px，行高 1.6–1.8；题目正文 18–20px
- 数学公式 LaTeX（KaTeX）渲染，字号与正文一致
- 全端支持大/中/小三档字号调节

## 7. 图表与公式

- 图表（Recharts）配色从 primary / success / warning 派生，低饱和，禁大红大绿相邻
- 公式渲染颜色使用 text-primary
