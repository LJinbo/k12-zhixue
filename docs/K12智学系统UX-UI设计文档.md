# K12 智学系统 UX/UI 设计文档 v1.0

> 依据：《K12 智学系统需求文档（PRD）v1.0》｜日期：2026-10-12｜状态：待评审
> v1.1（2026-10-13 变更）：P01 账号判定身份（无身份选择）；全学段统一暖橘红配色（唯一来源 [style.md](style.md)，删除学段主题皮肤）；P04 改为章节星链图（星球大小=章节重要度，点击展开小节）；全端禁止 emoji、禁止吉祥物与装饰性元素

## 1. 设计概述

### 1.1 设计范围
- 双端：学生端 + 家长端（同一系统、按角色区分）
- 双形态：WebApp + PC 桌面端，**共用同一设计系统**，以 PC 大屏（1280–1920px）优先设计，WebApp 响应式适配窄屏
- 共 19 个页面（学生端 13 + 家长端 6）

### 1.2 设计原则（按优先级）
1. **护眼第一**：所有视觉决策让位于眼睛健康（详见 §3）
2. **统一视觉**（2026-10-13 变更）：全学段共用同一套暖橘红配色（唯一来源 [style.md](style.md)）；无吉祥物、无装饰性元素、**禁止 emoji**；星链图星球为功能性可视化，不属于装饰
3. **低输入成本**：小学生可独立完成核心操作；能点选不打字、能拍照不手输
4. **专注防分心**：界面无娱乐化噪音，呼应「严禁与 AI 闲聊」——AI 对话区始终围绕学习内容
5. **激励可视化**：闯关、打卡、清错解锁、奖励的进度状态在界面上一眼可见

## 3. 设计规范

### 3.1 护眼视觉规范（最高优先级）

**配色唯一来源：[style.md](style.md)**（2026-10-13 变更：全学段统一暖橘红主题，不再按学段区分配色）

- 登录页与全部页面共用暖橘红暖色系；章节星链图星球配色见 style.md §3
- 两套模式（P13 手动切换 + 19:00 后自动建议切夜间）：
  - **标准**：暖米底 `#FAF1E8`、正文暖棕黑 `#43302A`、主操作橘红 `#D9541F`
  - **夜间**：暖深棕底 `#2A211B`、文字 `#F2E3D5`、低蓝光
- Tailwind Token 映射：`app/web/src/styles/theme.css`

**硬性禁令**：禁大面积纯白 `#FFFFFF` 背景；禁纯黑文字；禁高饱和大色块；禁闪烁/自动循环动画；奖励动效 ≤3 秒且可跳过；**禁止 emoji（文案/按钮/状态/图标一律不用）**；**禁止吉祥物与装饰性元素**。

**对比度**：正文与背景 ≥ 7:1（WCAG AAA）；辅助文字 ≥ 4.5:1。夜间模式下同样满足。

**字体**：中文黑体系（系统默认栈）；正文最小 16px；题目正文 18–20px；行高 1.6–1.8；数学公式 LaTeX 渲染、字号与正文一致；全端支持大/中/小三档字号调节。

### 3.2 护眼功能设计

| 功能 | 规格 |
|---|---|
| 用眼休息提醒 | 连续学习 30 分钟（家长可配 20/30/40 分钟）弹柔和全屏遮罩：「看看远处，休息 20 秒」+ 倒计时；一键关闭继续（强制锁屏留二期） |
| 休息计时浮标 | 学习页常驻小图标，显示距下次休息的剩余时间 |
| 模式切换 | 标准/夜间两模式，手动 + 时段自动建议 |
| 亮度异常提示 | 检测系统亮度过低/过高时温和提示（桌面端能力允许时） |
| 动效克制 | 无自动播放动画；转场 ≤200ms；奖励动效 ≤3 秒可跳过 |

### 3.3 学段差异（2026-10-13 变更：配色全学段统一，仅排版差异）

| 维度 | 小学 | 初中 | 高中 |
|---|---|---|---|
| 默认字号 | 18px | 17px | 16px |
| 圆角 | 16px | 12px | 8px |
| 信息密度 | 低、按钮大 | 中 | 高、紧凑 |
| 奖励呈现 | 小红花/奖杯 | 勋章+积分 | 积分+实物兑换 |

配色与视觉风格全学段统一（见 style.md），无学段专属皮肤、卡通吉祥物与装饰插画。
切换方式：随孩子档案的学段自动应用，P13 可手动微调。

### 3.4 通用布局骨架

- 页面内容区最大宽 1200px 居中，四周大留白
- 学生端：左侧 72px 图标导航（首页/课程/错题本/测评/答疑/奖励/设置）+ 顶栏（打卡天数·积分·护眼状态）
- 家长端：左侧带文字导航 + 顶栏多孩切换器

## 4. 页面详细设计

> 每页按「目标 / 入口 / 功能 / 输入 / 输出 / 布局」描述；关键页附线框图。

### P01 登录页（2026-10-13 变更：无身份选择）
- 目标：账号登录，系统按账号角色自动路由到对应端
- 输入：手机号/账号、密码
- 输出：登录态、按账号角色路由（学生端/家长端）
- 布局：居中卡片登录表单（账号/密码/登录按钮），无身份选择控件

### P02 首次使用向导
- 目标：3 步完成初始化——添加孩子（昵称/学段）→ 选年级与教材版本 → 选主题与护眼偏好
- 输入：孩子信息、教材版本、主题选择
- 输出：孩子档案、默认主题，进入对应端首页

### P03 学生首页
- 目标：一屏看清「今天学什么」，最快进入学习
- 输入：点击继续学习/任务卡片
- 输出：跳转记录、打卡状态上报
- 输出展示：今日学习时长、打卡状态、待清错题数
- 布局：

```
┌──────────────────────────────────────────────────────────────┐
│ 智学   首页 课程 错题本 测评 答疑 奖励   连续7天 积分128 标准模式 │
├────────────┬─────────────────────────────────────────────────┤
│ 数学        │  早上好，小明！今日已学习 25 分钟                  │
│ 语文(锁定)  │  ┌───────────┐ ┌───────────┐ ┌───────────┐      │
│ 英语(锁定)  │  │ 继续学习    │ │ 今日任务   │ │ 我的奖励   │      │
│            │  │ 三上·第2章  │ │ ✓打卡      │ │ 花x12 杯x3 │      │
│ (MVP仅数学) │  │ [进入星链图] │ │ □清错5题   │ │ 积分128    │      │
│            │  └───────────┘ └───────────┘ └───────────┘      │
│            │  本周打卡 一✓ 二✓ 三✓ 四✓ 五· 六· 日·             │
└────────────┴─────────────────────────────────────────────────┘
```

### P04 章节星链图（2026-10-13 变更）
- 目标：以星球呈现本学期章节与重要度，点击章节展开小节，管理预习/复习入口
- 输入：点星球（选中章节）、点小节、切预习/复习模式
- 输出：进入 P05；解锁状态计算展示
- 布局：主体为章节星链图（虚线星链 + 章节星球）；选中章节后，星链图下方展开该章全部小节列表

```
┌──────────────────────────────────────────────────────────────┐
│ 数学·三年级上          进度 3/8        [同步][预习][复习]       │
├──────────────────────────────────────────────────────────────┤
│   (时分秒)····(万以内的加减法)····(测量)····(倍的认识)····      │
│   小星球       大星球·进行中       中星球      小星球           │
│  星球大小 = 章节重要度：大(重点)/中(普通)/小(次要)                │
│  状态：已完成(暖橙)/进行中(橘红光环)/未解锁(灰米色)               │
├──────────────────────────────────────────────────────────────┤
│ 第2章 万以内的加减法  [重点·大星球]  状态:进行中                  │
│  1 加法           已完成   [复习]                              │
│  2 减法           进行中   [进入]                              │
│  3 整理和复习      未解锁   先完成上节并清空错题                 │
└──────────────────────────────────────────────────────────────┘
```
- 星球规格：大 88px / 中 68px / 小 52px；配色见 style.md §3（星球为功能性可视化，非装饰）
- 状态：已完成 / 进行中 / 未解锁，一律文字标注，不用图形符号
- 预习模式：后续章节临时可进（弱化解锁）；复习模式：任意已学章节可重学

### P05 学习页（核心页）
- 目标：一屏完成「AI 分步引导 + 作答」，孩子不需要切页面
- 入口：关卡地图当前关
- 功能：按预制框架分步推进（讲解→例题→练习循环）；AI 对话引导；作答与即时判分；步骤进度；用时统计
- 输入：作答（点选/填空/拍照）、对话消息、上下步操作
- 输出：答题记录（对→学情；错→自动入错题本）、对话记录、步骤完成状态、学习时长
- 布局：左侧内容舞台（60%）+ 右侧 AI 对话区（40%）

```
┌──────────────────────────────────────────────────────────────┐
│ ← 第5课 分数的初步认识  第2步/共6步   用时12:30  距休息17:30     │
├──────────────────────────────┬───────────────────────────────┤
│  内容舞台                     │  AI老师·小智                    │
│                              │ ┌───────────────────────────┐ │
│  把一个苹果平均分成 2 份，      │ │ 每一份就是这个苹果的多少呢？ │ │
│  每一份就是它的——              │ └───────────────────────────┘ │
│                              │  说说你的想法吧                 │
│  ┌──────────────────────┐   │                               │
│  │ ○ 二分之一  ○ 一半咬掉 │   │ ┌───────────────────┐       │
│  └──────────────────────┘   │ │ 说点什么… [拍照] │ 发送 │     │
│  [提交答案]                  │ └───────────────────┘       │
├──────────────────────────────┴───────────────────────────────┤
│ 哪里没懂？点文字问小智       [上一步]  本关错题 0  [下一步·锁]   │
└──────────────────────────────────────────────────────────────┘
```
- 关键交互：
  - 答错反馈：柔和橙提示「再想想，提示 1/3」，不出红叉大动画；提示轮次用尽后 AI 逐步讲解
  - 题干文字可划选直接向 AI 提问（降低输入门槛）
  - 对话区仅限本课内容，偏离话题时 AI 温和拉回（护栏的 UI 呈现：不提供无关话题的快捷入口）
- 护眼要点：内容舞台底色 bg-card，无纯白；对话气泡低对比描边；顶栏常驻休息倒计时

### P06 错题本
- 目标：错题按知识点组织，突出「清错=解锁」动机
- 输入：筛选（学科/单元/知识点/状态）、点重做、点看讲解
- 输出：进入 P07；错题统计展示
- 布局：

```
┌──────────────────────────────────────────────────────────────┐
│ 错题本  [数学|语文|英语]  [单元▾][知识点▾]  (待清错5 · 已清12)    │
├──────────────────────────────────────────────────────────────┤
│ 待清错 (5) —— 清空后即可解锁下一关！                         │
│ ┌──────────────────────────────────────────────────────────┐ │
│ │ 1/2 + 1/4 = ?      [分数运算] 第5课 · 错2次                │ │
│ │                                   [重做]  [听小智讲解]      │ │
│ └──────────────────────────────────────────────────────────┘ │
│ 已清错 (12)   本周遗忘曲线复习推荐 3 题                   │
└──────────────────────────────────────────────────────────────┘
```

### P07 清错模式
- 复用 P05 的作答态：左题目右 AI 讲解；顶部改为「清错进度 2/5」，清错完成弹通关庆祝（≤3 秒可跳过）
- 输入：重做作答；输出：错题清除状态→关卡解锁计算

### P08 测评列表
- 目标：按单元/期中期末组织测评入口
- 输入：点开始测评；输出：进入 P09
- 布局：卡片列表（测评名/范围/题数/时长/历史最好成绩），未解锁灰置

### P09 答题页（测评）
- 与 P05 差异：**无 AI 提示**（防作弊逻辑）、题号导航格、整卷倒计时、交卷二次确认
- 输入：作答、上/下一题、标记疑难题；输出：答卷数据→判题（客观题即时，主观题 AI 评阅）
- 布局：左侧题干+作答区，右侧题号导航+倒计时卡

### P10 测评报告
- 输出展示：得分/用时、知识点掌握雷达或条形、错题清单（错题已在系统内自动进入错题本）、薄弱点结论
- 输入：点错题回看、点「针对薄弱点练习」→ P04 复习模式
- 护眼要点：图表用低饱和色系，禁大红大绿

### P11 作业答疑
- 目标：系统外题目（学校作业）的即时引导答疑
- 输入：拍照上传（OCR 后可手动修正识别结果）、追问文字
- 输出：AI 引导对话（引导 N 轮后按家长配置开放「看完整解析」）；**明确标识不进错题本**
- 布局：

```
┌──────────────────────────────────────────────────────────────┐
│ 作业答疑   ⓘ 本页仅即时答疑，题目不会存入错题本                  │
├──────────────────────────────────────────────────────────────┤
│  ┌──────────────┐  AI：先读题——小明走了 2/5，还剩…             │
│  │ [拍照/上传]  │  你觉得剩下的是几分之几？                     │
│  │  识别结果可编辑│                                            │
│  └──────────────┘  [输入框…           ] [提示1] [看解析·锁]    │
└──────────────────────────────────────────────────────────────┘
```
- 「看解析」按钮默认锁定，悬浮提示「引导 3 轮后开放（家长可调）」

### P12 奖励中心
- 功能：我的奖励（小红花/奖杯/勋章/积分）、打卡日历、兑换商城（中学：实物兑换申请）
- 输入：兑换申请；输出：申请单→家长端审核流
- 布局：页签「我的奖励｜兑换商城｜打卡日历」；小学主题以动画徽章墙为主，高中主题以积分清单为主

### P13 学生设置
- 功能：主题三模式切换、字号调节、休息提醒间隔查看、账号信息
- 输出：偏好写回孩子档案

### P14 家长总览
- 目标：30 秒了解孩子今天学得怎样
- 输入：切换孩子、点报告入口；输出：跳转 P15–P17
- 布局：

```
┌──────────────────────────────────────────────────────────────┐
│ 家长中心   [小明 ▾]   总览 报告 学习记录 错题 奖励管理 设置        │
├────────────┬─────────────────────────────────────────────────┤
│ 今日 45min │ ┌─────────┐ ┌─────────┐ ┌─────────┐             │
│ 打卡 ✓    │ │本周时长   │ │课程进度  │ │待清错题  │             │
│ 休息提醒已开启 │ │ 3.5 小时 │ │ 62%▓▓▓░ │ │ 5 题    │             │
│            │ └─────────┘ └─────────┘ └─────────┘             │
│            │ 薄弱：分数运算(错3) · 单位换算(错2)                │
│            │ [查看 AI 周报 →]                                 │
└────────────┴─────────────────────────────────────────────────┘
```

### P15 学情报告
- 功能：AI 周报/月报——时长趋势、课程进度、薄弱知识点、AI 生成的学习建议
- 输入：选择周期（周/月）、一键生成 AI 报告
- 输出：报告展示与留存

### P16 学习记录
- 功能：时间线视图（学了哪课/做了哪些题/用时）+ AI 对话记录回看
- 输入：按日期筛选、点开某次学习详情
- 输出：明细展示（监督用途）

### P17 错题与薄弱点
- 功能：知识点维度的错题分布热力列表（与 P06 数据同源，家长视角）
- 输入：按学科/时间筛选
- 输出：薄弱点排名与趋势

### P18 奖励管理
- 功能：奖励池管理（虚拟/实物条目增删改）、积分规则配置、兑换申请审核（同意→标记已兑现）
- 输入：奖励条目操作、审批动作
- 输出：奖励池数据、审核结果→学生端 P12 同步

### P19 家长设置
- 功能：孩子档案管理（增改/学段）、教材版本绑定、答疑「看解析」引导轮数设置、休息提醒间隔（20/30/40 分钟）、话题护栏开关

## 5. 核心组件规范

| 组件 | 规格 |
|---|---|
| 题目卡 | 题干 18–20px；选项点击区 ≥48px；作答后内联反馈（正确：绿色勾+1 行肯定语；错误：橙提示「再想想+提示」），禁红叉动画 |
| AI 对话气泡 | AI 左侧圆角气泡（bg-elevated）；孩子右侧 primary-soft；底部输入框含拍照与发送；引导轮次进度以 1/3 圆点显示 |
| 章节星球 | 直径 88/68/52px（重要度三档），三态（已完成/进行中/未解锁，文字标注），未解锁悬浮显示解锁条件 |

| 奖励动效 | ≤3 秒、可点击跳过、结束后静置展示 |

## 6. 响应式与端差异

- ≥1280px：完整双栏布局；768–1279px：AI 对话区折叠为可展开抽屉；<768px（平板/手机浏览器访问 WebApp）：单列流式，作答与拍照答疑优先保证可用
- PC 桌面端 = WebApp 壳（同一前端工程），额外提供全局快捷键：`←/→` 步骤切换、`Enter` 发送、`Esc` 关闭弹层

## 7. 可用性与无障碍

- 儿童可用：大点击区（≥48px）、图标+文字双标识、破坏性操作二次确认、错答可无限重试不惩罚
- 视觉无障碍：对比度 AAA、三档字号、纯键盘可完成答题主流程
- 语言：全中文口语化文案；AI 名称统一为「小智」，仅作称呼、不出现卡通形象与吉祥物；语气鼓励不评判
