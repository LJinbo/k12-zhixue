# K12 智学系统需求文档（PRD）v1.0

> 版本：v1.0 ｜ 日期：2026-10-12 ｜ 状态：待评审

## 1. 背景与目标

### 1.1 背景与痛点
- 孩子学习中经常遇到知识盲点，家长要么没时间、要么水平有限，无法有效辅导
- 课外培训班水平参差不齐，费用高且效果难以保证
- 实践验证：AI 引导式辅导效率高——孩子某个知识点不会时，AI 分步引导可让孩子真正听懂（语、数、英均有效）

### 1.2 产品愿景
以 AI 为核心构建一套 K12 智学系统，让孩子学得轻松、效率更高，同时培养**自学能力**，摆脱对课外班和家长辅导的依赖。

### 1.3 建设策略
- 第一阶段：家庭自用（自家孩子），快速验证 AI 辅导效果
- 架构按多用户产品设计，验证成功后产品化

## 2. 用户与角色

| 角色 | 说明 |
|---|---|
| 学生 | K12 全学段（小学/初中/高中），系统主要使用者 |
| 家长 | 监督学情、管理奖励、配置孩子信息 |

- 一个家庭账号支持关联**多个孩子**（多学生）
- 无教师角色

## 3. 产品形态

- **WebApp**（浏览器访问）+ **PC 桌面端应用**
- 学生端与家长端同系统、按角色区分权限与视图
- **登录即定身份**：系统按账号角色自动路由到学生端/家长端，不提供身份选择步骤（2026-10-13 变更）

## 4. 系统总体架构

```
zhixueProject/
├── base/                        # 数据生产层
│   ├── paper-crawler/           # 试卷爬虫：抓取公开题库网站试卷与题目
│   └── paper-analysis/          # 试卷分析与整理：题目结构化、知识点标注、内容预制
└── app/                         # 应用层
    ├── agent/                   # AI Agent：引导教学、答疑、判题辅助、话题护栏
    ├── teaching-system/         # 教学系统：同步课程关卡、预习复习、测评、打卡奖励
    ├── mistake-book/            # 错题本系统：错题收录、清错、薄弱点分析
    └── admin/                   # 家长管理系统：学情报告、监督、奖励管理
```

## 5. 数据建设（base 层）

### 5.1 试卷爬虫（paper-crawler）
- **目标**：公开题库/试卷资源网站的试卷、题目、答案、解析
- **范围**：K12 全学段、全学科（内容覆盖随爬取自然积累）
- **要求**：题目去重、图片/公式资源本地化、增量抓取调度、抓取失败重试
- **合规约束**：现阶段仅限家庭自用；产品化前需解决内容版权授权（见 §10）

### 5.2 试卷分析与整理（paper-analysis）
- **题目结构化**：题型、难度、答案、解析、图片、公式（LaTeX 化）
- **知识点标注**：基于国家课程标准构建统一知识点体系，用 AI 批量标注、抽样人工校验
- **教材映射**：多教材版本（人教/北师大/苏教/外研等）目录 → 统一知识点体系
- **内容预制**：为每课（每关）生成教学框架——学习目标、讲解要点、例题序列、练习题组（AI 预生成 + 抽样人工审核后入库）
- **变式关联**：相似题、变式题关联，支撑错题再练

## 6. 核心业务场景（app 层）

### 6.1 同步校内课程（teaching-system）
- 学生选择**年级 + 教材版本**，系统呈现对应课程目录
- **章节星链图**（2026-10-13 变更）：本学期章节以星球呈现——重要章节为大星球、次要章节为小星球（大/中/小三档），章节间以星链相连；点击章节后在星链图下方展开该章全部小节；不使用吉祥物与装饰元素
- **一课一关**：关卡内容 = 预制教学框架 + AI 实时引导对话（AI 按框架分步引导，动态回应孩子疑问）
- **掌握式晋级**：完成本关练习且**清空本关错题**后解锁下一关；每单元结束后需清空单元错题方可进入下一单元
- **每日打卡**：记录学习出勤与连续学习天数

### 6.2 错题本（mistake-book）
- **来源**：系统内练习、测验产生的错题自动收录（学校考试错题不进系统，已确认接受）
- **归类**：按学科、单元、知识点组织
- **清错**：错题重做答对（或 AI 确认已掌握）即清除；清错是晋级的前置条件
- **薄弱点分析**：基于错题分布输出薄弱知识点，驱动变式再练
- **周期复习**：按遗忘曲线推荐已清错题的周期性回顾（可选增强项）

### 6.3 自主预习 / 复习
- 预习：AI 引导孩子提前学习后续课程内容
- 复习：按单元/知识点自主回顾 + 配套练习
- 不强制跟随学校进度，孩子可自定节奏

### 6.4 测评系统（teaching-system）
- **测评类型**：单元测试、期中/期末模拟卷
- **组卷**：从题库按知识点/难度自动组卷
- **自动判题**：客观题自动判分；主观题 AI 评阅（家长可复核）
- 测验错题自动进入错题本，结果沉淀到学情数据

### 6.5 作业答疑（agent）
- **输入**：拍照 OCR 识别系统外题目（如学校作业题）；仅用于即时答疑，**不入错题本**
- **方式**：AI 分步引导讲解，鼓励讨论与追问
- **教育策略**：默认引导优先（先提示思路，逐步推进）；家长可配置「引导轮数后允许查看完整解析」

### 6.6 AI Agent 能力（agent）
- 分步引导教学（苏格拉底式追问）、答疑讨论、主观题评阅辅助、学情分析支持
- **模型接入**：国内大模型 API（DeepSeek / 通义千问 / GLM 等），抽象接入层、支持切换
- **硬性约束——严禁闲聊**：话题护栏，AI 仅围绕学习内容对话；偏离学习话题一律拉回；护栏策略需对抗孩子的「套话」尝试（如直接索要答案）

## 7. 游戏化与激励

- **打卡闯关**：每日打卡 + 关卡推进
- **奖励体系**：
  - 小学：虚拟奖励——小红花、奖杯、勋章等
  - 中学：实物奖励——家长配置奖励池（如耳机、实现一个愿望等），孩子通过学习积累积分兑换，**家长审核兑现**
- 清错题解锁机制本身构成核心激励闭环（「清掉错题才能开新关」）

## 8. 家长管理系统（admin）

| 模块 | 功能 |
|---|---|
| 学情报告 | 学习时长、课程进度、错题情况、薄弱知识点；AI 生成周报/月报 |
| 监督 | 查看孩子学习记录、答题记录、AI 对话记录 |
| 奖励管理 | 奖励池配置（虚拟/实物）、积分规则、兑换审核与兑现登记 |
| 设置 | 孩子信息管理、教材版本绑定、答疑「直接看解析」开关等 |

## 9. 非功能需求

- **账号体系**：家庭账号（家长 + 多学生）；架构预留多家庭产品化扩展（多租户）
- **未成年人保护与内容安全**：AI 输出内容安全过滤；禁闲聊护栏；防沉迷（家长端可查看时长，管控功能列为后续增强）
- **数据隐私**：孩子学习数据仅家庭内可见
- **成本控制**：预制框架降低实时 token 消耗；模型可按性价比切换
- **可用性**：小学生可独立完成核心操作（界面友好、输入成本低——答疑以拍照替代打字）
- **全局视觉**（2026-10-13 变更）：配色唯一来源 [style.md](style.md)——暖橘红主题**全学段统一**；**禁止 emoji**；**禁止吉祥物与装饰性元素**

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| 爬虫内容的版权风险 | 自用期控制传播；产品化前采购授权或转为自制内容 |
| 爬取数据质量参差 | 清洗 + AI 校验 + 抽样人工审核 |
| AI 讲解质量波动 | 预制框架保证下限；对话日志抽样质检 |
| 全学段内容工程量大 | 知识点体系一次建好，题目内容随爬虫积累；运营期可聚焦孩子当前学段优先补齐 |
| 孩子诱导 AI 直接给答案 | 护栏提示词 + 引导轮数策略 + 家长端对话可查 |

## 11. 里程碑建议

| 阶段 | 范围 |
|---|---|
| 一期（MVP） | 爬虫 + 题库结构化 + 知识点标注；同步课程关卡（单科先行，建议数学）+ AI 引导 + 清错晋级；错题本；家长基础报告 |
| 二期 | 测评系统（组卷/判题）；拍照 OCR 答疑；预习复习场景；游戏化奖励完整版（含实物兑换）；多教材版本扩展、多学科铺开 |
| 三期（产品化） | 多家庭账号、内容版权合规、防沉迷管控、支付体系 |
