## 0. 技术栈（已确认 2026-10-13）

| 层 | 选型 | 理由 |
|---|---|---|
| 工程结构 | pnpm monorepo | base/* 与 app/* 各为独立包，统一管理 |
| 前端 | React 18 + TypeScript + Vite + Tailwind CSS 4 | Tailwind 变量体系便于实现护眼色板与三主题切换 |
| 桌面端 | Electron 壳（复用 Web 构建） | PC App = WebApp 壳，UX §6 |
| 后端 | Node.js 20 + NestJS 11 | **用户指定**；app/server |
| 数据库 | PostgreSQL 16 + Prisma（app 层 ORM） | 家庭自用期可降级 SQLite；base 层 Python 管道用 psycopg 直连 |
| LLM 接入 | OpenAI 兼容协议适配层 | DeepSeek / GLM / 通义千问可切换（PRD §6.6） |
| 爬虫/数据管道 | Python（Scrapy + Playwright） | 仅 base 层数据生产使用 Python，与 app 层 TypeScript 栈解耦 |
| 公式/图表 | KaTeX（公式）、Recharts（低饱和图表） | UX §3.1、§4-P10 |
